# AI агент бүтээх

Код, терминал мэдэхгүй хүнд ч анхны агентаа барихад туслах ажлын урсгал.

## Үндсэн ойлголт
- **Агент** — зорилго өгөхөд өөрөө алхмаа төлөвлөж, хэрэгсэл ашиглан ажлыг дуусгадаг AI. Чатаас ялгаа нь: хариулт биш, *гүйцэтгэсэн ажил* буцаана.
- **Subagent** — том ажлыг жижиг хэсгүүдэд хувааж, зэрэг (параллель) гүйцэтгэдэг туслах агентууд. Жишээ: 10 даалгавартай жагсаалтыг 10 subagent нэгэн зэрэг хийнэ.
- **Human in the loop** — илгээх, нийтлэх, устгах зэрэг буцаах боломжгүй үйлдлийг агент өөрөө хийхгүй, ноорог бэлдээд хүнээр батлуулна.

## Ажлын алхам

### 1. Brain dump — хэрэглэгчээс бүгдийг асуух
Дараах зүйлсийг тодруулна (мэдэгдэж байгааг дахин асуухгүй):
- Агент ямар асуудал шийдэх вэ? Өдөр бүр юу хийдэг вэ?
- Оролт юу вэ (жагсаалт, файл, имэйл, мэдээллийн сан)?
- Гаралт юу вэ (ноорог, тайлан, хүснэгт, dashboard)?
- Ямар хэрэгсэл/холболт хэрэгтэй (Gmail, Drive, вэб хайлт, файл)?
- Юуг ЗААВАЛ зөвшөөрөл авч хийх вэ?
- Ямар хэлээр, ямар хэв маягаар ажиллах вэ?

### 2. CLAUDE.md бичих
Агентын "тархи" болох зааврын файл. Загвар:

```markdown
# [Агентын нэр]

## Зорилго
[Нэг өгүүлбэрээр юу хийдэг]

## Хэрэглэгч
[Хэн, ямар ажил хийдэг, ямар хэв маяг илүүд үздэг]

## Ажлын урсгал
1. [Оролтыг хүлээн авах]
2. [Даалгавар бүрийг ангилах]
3. [Бие даасан даалгавруудыг subagent-аар зэрэг гүйцэтгэх]
4. [Үр дүнг нэгтгэж харуулах]

## Дүрэм
- Имэйл, мессеж илгээх, нийтлэх, устгахаас өмнө ЗААВАЛ ноорог үзүүлж зөвшөөрөл авна.
- Тодорхойгүй зүйлийг таахгүй, асууна.
- [Хэлний/форматын шаардлага]

## Гаралт
[Үр дүн ямар хэлбэртэй байх]
```

### 3. Plan mode-оор эхлээд төлөвлөх
Шууд барихгүй. Эхлээд төлөвлөгөө гаргаж хэрэглэгчээр батлуулна: ямар дэлгэц/хэсэг, ямар товч, ямар өгөгдөл хадгалах, subagent хэрхэн хуваарилагдах.

### 4. Барих
- Энгийн интерфэйс: оролт оруулах талбар + нэг гол товч (жишээ: "Гүйцэтгэх").
- Dashboard/artifact хэлбэрээр хийвэл утаснаас ч нээгдэнэ, компьютер унтраастай ч ажиллана.
- Давтагдах ажлыг scheduled task болгож болно.

### 5. Subagent-аар зэрэг гүйцэтгэх
- Бие биеэсээ хамааралгүй даалгавруудыг зэрэг өгнө; хамааралтайг дарааллаар.
- Subagent бүрт бүрэн контекст өгнө (тэд үндсэн яриаг харахгүй).
- Үр дүнг нэгтгэж, юу хийгдсэн / юу батлуулах шаардлагатайг тусад нь харуулна.

### 6. Human in the loop
- Имэйл → ноорог (Drafts) үүсгэнэ, илгээхгүй.
- Файл устгах, нийтлэх, худалдан авах → жагсаалт гаргаж зөвшөөрөл авна.

### 7. Чанарыг шалгаж сайжруулах
Эхний хувилбар ихэвчлэн төгс биш. "Илүү сайн болго" гэхийн оронд тодорхой зааж сайжруулна: аль хэсэг, ямар өнгө/бүтэц, ямар алхам дутуу.

## Санаа: ШЕЗ-ийн ажилд хэрэглэх жишээ агентууд
- Өдрийн тайлан агент — хийсэн ажлуудыг цуглуулж тайлан ноороглоно.
- Албан бичиг агент — хүсэлтийг ангилж, docbay/jud-rule-skill-ээр ноорог бэлдэнэ.
- Имэйл ангилагч агент — ирсэн бичгийг ангилж, хариуны ноорог бэлдэнэ (илгээхгүй).
