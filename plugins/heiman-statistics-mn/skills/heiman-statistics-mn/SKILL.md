# Зан үйлийн шинжлэх ухааны статистик (Heiman, 6 дахь хэвлэл) — монгол хэлээр

Энэ skill нь Gary W. Heiman-ы *Basic Statistics for the Behavioral Sciences* (6th ed.) номын бүтэц, тэмдэглэгээ, алхамчилсан аргачлалд тулгуурлан статистикийг **монгол хэлээр** тайлбарлах, бодлого бодох, өгөгдөлд тохирох арга сонгох, үр дүнг тайлагнахад зориулагдсан. Номын эх бичвэрийг хуулбарлахгүй; ойлголт, томьёо, алхмыг өөрийн үгээр монголоор тайлбарлана.

## Хэзээ ашиглах

- "Статистикийн бодлого бодож өг", "t-тест гэж юу вэ", "ANOVA тайлбарла", "аль шинжилгээг сонгох вэ"
- Сэтгэл судлалын хичээл, курсын ажил, дипломын судалгааны өгөгдөл боловсруулах
- "Heiman-ы номын N-р бүлэг", "номын дасгал", шалгалтад бэлтгэх, асуулт сорил хийлгэх
- SPSS-ийн гаралтыг унших, үр дүнг APA хэв маягаар бичих

## Ажиллах зарчим

1. **Хэл:** Хариуг монголоор өгнө. Нэр томьёог анх дурдахдаа англи эхийг хаалтад бичнэ: "стандарт хазайлт (standard deviation)". Тэмдэглэгээг (X̄, s, H₀, t_obt, F_crit, η²) номынхоор хэвээр үлдээнэ.
2. **Түвшин тогтоох:** Хэрэглэгч ойлголт асууж байна уу (тайлбар), бодлого бодуулж байна уу (тооцоо), өгөгдөлд арга сонгуулж байна уу (шийдвэр) гэдгийг эхлээд ялгана.
3. **Заах арга (номын хэв маяг):** Яагаад хэрэгтэй вэ → ойлголтын логик → томьёо → жижиг тоон жишээ → тайлбар/дүгнэлт → өөрөө бодох 1–2 дасгал (хариутай). Томьёог цээжлүүлэхээс илүү "энэ тоо юу хэлж байна вэ" гэдгийг онцлоно.
4. **Бодлого бодох:** Алхам бүрийг харуулна (Σ-уудыг хүснэгтээр). Дунд шатны тоог тасалж бүү дугуйл; эцсийн хариуг эх өгөгдлөөс 2 орон илүү нарийвчлалтай (ихэвчлэн 2 бутархай орон) өгнө. Боломжтой бол тооцоог кодоор (Python: numpy/scipy) ажиллуулж шалгана; критик утгыг хүснэгтийн оронд `scipy.stats`-аас авч болно (жишээ нь `t.ppf(1-α/2, df)`), ингэхдээ номын хүснэгтийн утгаас бага зэрэг зөрж болохыг хэлнэ.
5. **Таамаглал шалгах бүрд:** урьдчилсан нөхцөл шалгах → H₀, Hₐ бичих → α сонгох (анхдагч .05), нэг/хоёр талт → статистик бодох → критик утгатай харьцуулах → шийдвэр → нөлөөний хэмжээ, итгэх интервал → агуулгын (сэтгэл судлалын) дүгнэлт.
6. **Болгоомжтой дүгнэх:** Ач холбогдолгүй гарвал "хамаарал байхгүй нь батлагдлаа" гэж бүү хэл — H₀-ийг няцааж чадсангүй, дүгнэлт хийхгүй. Корреляци шалтгааныг батлахгүй. Статистик ач холбогдол ≠ практик ач холбогдол (нөлөөний хэмжээг заавал мэдээл).
7. Номын тодорхой хуудас, дасгалын дугаар шаардсан бол хэрэглэгчээс номын PDF-ийг хавсаргахыг хүсэж, тэндээс уншина; хуудасны дугаарыг таамаглаж бүү бич.

## Томьёоны лавлах

Номын онцлог тэмдэглэгээ: **том S** = түүврийг дүрслэх (N-д хуваана), **жижиг s** = эх олонлогийг үнэлэх (N−1-д хуваана), **σ** = эх олонлогийн жинхэнэ утга. SPSS болон ихэнх программ жижиг s-ийг (N−1) өгдөг.

**Давтамж, төвийн хандлага (3–4-р бүлэг)**
- rel. f = f / N; хувь = rel. f × 100; перцентиль = (cf / N) × 100
- X̄ = ΣX / N; Σ(X − X̄) = 0
- Хазгай тархалтад голч, хэвийн тархалтад дундаж

**Хэлбэлзэл (5)**
- Далайц = хамгийн их − хамгийн бага
- Түүврийн вариац: S²ₓ = [ΣX² − (ΣX)²/N] / N; Sₓ = √S²ₓ
- Үнэлсэн вариац: s²ₓ = [ΣX² − (ΣX)²/N] / (N − 1); sₓ = √s²ₓ; df = N − 1
- Хэвийн тархалтад онооны ~68% нь X̄ ± 1S дотор

**z-оноо (6)**
- z = (X − X̄)/Sₓ (эх олонлогт (X − μ)/σₓ); X = z·Sₓ + X̄
- Дунджийн стандарт алдаа: σ_X̄ = σₓ/√N; түүврийн дунджийн z = (X̄ − μ)/σ_X̄
- z-хүснэгт: дундаж ба z-ийн хоорондох талбай, z-ээс цаашхи талбай → харьцангуй давтамж, перцентиль, магадлал

**Корреляци (7)**
- Пирсон: r = [N·ΣXY − ΣX·ΣY] / √{[N·ΣX² − (ΣX)²][N·ΣY² − (ΣY)²]}
- Спирмен: r_S = 1 − 6ΣD² / [N(N² − 1)] (D = хос эрэмбийн зөрүү)
- Тэмдэг = чиглэл, абсолют утга = хүч (0…±1). Шугаман бус хамаарал, далайц хязгаарлагдах (restriction of range) асуудлыг шалга.

**Регресс (8)**
- Y′ = bX + a; b = [N·ΣXY − ΣX·ΣY] / [N·ΣX² − (ΣX)²]; a = Ȳ − b·X̄
- S_Y′ = S_Y·√(1 − r²); r² = тайлбарлагдсан вариацын хувь; 1 − r² = тайлбарлагдаагүй хувь

**Магадлал (9)**
- p(үйл явдал) = тухайн үйл явдлын харьцангуй давтамж; хэвийн муруйн талбай = магадлал
- Түүврийн дундаж няцаах мужид (α = .05, хоёр талт: z_crit = ±1.96; нэг талт: 1.645) унавал тухайн эх олонлогийг төлөөлөх магадлал багатай

**z-тест (10)** — σₓ мэдэгдэж байгаа үед
- z_obt = (X̄ − μ)/σ_X̄, σ_X̄ = σₓ/√N
- I төрлийн алдаа: үнэн H₀-ийг няцаах (магадлал = α). II төрлийн алдаа: худал H₀-ийг хадгалах (β). Чадал = 1 − β.

**Нэг түүврийн t-тест (11)**
- s_X̄ = √(s²ₓ/N); t_obt = (X̄ − μ)/s_X̄; df = N − 1
- Итгэх интервал: (s_X̄)(−t_crit) + X̄ ≤ μ ≤ (s_X̄)(+t_crit) + X̄ (хоёр талт t_crit)
- r-ийн ач холбогдол: H₀: ρ = 0; r_obt-ийг r_crit-тэй харьцуулна, df = N − 2 (Спирменд N-ээр)
- Чадлыг нэмэгдүүлэх: нөхцөлүүдийн ялгааг томруулах, нөхцөл доторх хэлбэлзлийг багасгах, N-ийг ихэсгэх

**Хоёр түүврийн t-тест (12)**
- Бие даасан: s²_pool = [(n₁−1)s²₁ + (n₂−1)s²₂] / [(n₁−1) + (n₂−1)]
  s_(X̄₁−X̄₂) = √[s²_pool(1/n₁ + 1/n₂)]; t_obt = [(X̄₁ − X̄₂) − (μ₁ − μ₂)] / s_(X̄₁−X̄₂); df = (n₁−1) + (n₂−1)
- Хамааралтай: D = хос онооны зөрүү; s²_D = [ΣD² − (ΣD)²/N]/(N−1); s_D̄ = √(s²_D/N); t_obt = (D̄ − μ_D)/s_D̄; df = N − 1 (N = хосын тоо)
- Нөлөөний хэмжээ: Коэний d = (X̄₁ − X̄₂)/√s²_pool (хамааралтайд D̄/√s²_D); ≈.2 бага, .5 дунд, .8 их
  r²_pb = t²_obt / (t²_obt + df); бодит судалгаанд ихэвчлэн .10–.30, .30-аас дээш бол маш их

**Нэг хүчин зүйлийн ANOVA (13)**
- H₀: μ₁ = μ₂ = … = μ_k; Hₐ: бүх μ тэнцүү биш
- SS_tot = ΣX²_tot − (ΣX_tot)²/N; SS_bn = Σ[(бүлгийн ΣX)²/n] − (ΣX_tot)²/N; SS_wn = SS_tot − SS_bn
- df_bn = k − 1; df_wn = N − k; df_tot = N − 1; MS = SS/df; F_obt = MS_bn/MS_wn
- Тьюки HSD = q_k·√(MS_wn/n) — хоёр дунджийн зөрүү HSD-ээс их бол ач холбогдолтой
- Фишерийн хамгаалагдсан t: t_obt = (X̄₁ − X̄₂)/√[MS_wn(1/n₁ + 1/n₂)], df = df_wn
- η² = SS_bn/SS_tot; нэг μ-ийн итгэх интервал: (√(MS_wn/n))(±t_crit) + X̄, df = df_wn
- F ач холбогдолтой, k > 2 үед л post hoc хийнэ

**Хоёр хүчин зүйлийн ANOVA (14)**
- Гурван F: A үндсэн нөлөө, B үндсэн нөлөө, A×B харилцан үйлчлэл; тус бүр MS_wn-д хуваагдана
- df_A = k_A − 1; df_B = k_B − 1; df_A×B = df_A·df_B; df_wn = N − k_A·k_B
- SS_A×B = SS_bn(нийт) − SS_A − SS_B
- Харилцан үйлчлэл: нэг хүчин зүйлийн нөлөө нөгөөгийн түвшнээс хамаарч өөрчлөгдөнө (график дээр шугамууд параллель биш). Ач холбогдолтой бол үндсэн нөлөөг болгоомжтой тайлбарлана.
- Харилцан үйлчлэлийн post hoc: зөвхөн нэг хүчин зүйлээр ялгаатай (unconfounded) нүднүүдийг харьцуулна; HSD-д тохируулсан k ашиглана
- η² = тухайн нөлөөний SS_bn / SS_tot

**Хи-квадрат (15)**
- χ²_obt = Σ[(f_o − f_e)²/f_e]
- Нэг хэмжээст (тохирлын шалгуур): f_e = N/k (тэнцүү хуваарилалтын H₀ үед); df = k − 1
- Хоёр хэмжээст (хамааралгүй байдал): f_e = (мөрийн нийлбэр × баганын нийлбэр)/N; df = (мөр − 1)(багана − 1)
- Нөхцөл: ажиглалт бүр нэг л ангилалд, хамааралгүй; f_e ≥ 5
- Хамаарлын хүч: 2×2 бол φ = √(χ²/N); бусад үед C = √[χ²/(N + χ²)]; квадрат нь тайлбарлагдсан хувь

**Эрэмбийн параметрийн бус тестүүд (15)**
- Бүх оноог нийтэд нь эрэмбэлнэ; тэнцсэн оноонд эзлэх байруудын дунджийг өгнө
- Манн–Уитни: U₁ = n₁n₂ + n₁(n₁+1)/2 − ΣR₁ (U₂ мөн адил); хоёр талтад бага U-г авч, U_obt ≤ U_crit бол ач холбогдолтой
- Эрэмбийн нийлбэрийн тест: ΣR_exp = n(N+1)/2; z_obt = (ΣR − ΣR_exp)/√[n₁n₂(N+1)/12]; η² = z²/(N−1)
- Вилкоксон T: тэг биш зөрүүнүүдийг абсолют утгаар эрэмбэлж, эерэг/сөрөг эрэмбийн нийлбэрийн багыг T_obt гэнэ; T_obt ≤ T_crit бол ач холбогдолтой (N = тэг биш зөрүүний тоо)
- Крускал–Уоллис: H = [12/(N(N+1))]·Σ[(ΣR)²/n] − 3(N+1); df = k − 1; χ² хүснэгт; η² = H/(N−1)
- Фридман: χ² = [12/(N·k(k+1))]·Σ(ΣR)² − 3N(k+1); df = k − 1 (оролцогч бүрийн дотор эрэмбэлнэ)
- U ба T-д бага утга ач холбогдолтой гэдгийг (бусад тестээс эсрэгээр) онцол.

## Таамаглал шалгах алхмын загвар

Хариуг дараах бүтцээр өг:

1. **Загвар ба тест:** хэдэн түүвэр, хамааралтай эсэх, хэмжилтийн шкал → сонгосон тест, урьдчилсан нөхцөл
2. **Таамаглал:** H₀ ба Hₐ (тэмдэглэгээгээр болон үгээр), нэг/хоёр талт
3. **α ба критик утга:** df, критик утга
4. **Тооцоо:** завсрын нийлбэрүүд, статистик үзүүлэлт
5. **Шийдвэр:** obt нь crit-ээс цааш бол H₀-ийг няцаана — "ач холбогдолтой"; үгүй бол хадгална — дүгнэлт хийхгүй
6. **Нөлөөний хэмжээ ба итгэх интервал** (ач холбогдолтой үед)
7. **Дүгнэлт:** судалгааны агуулгаар энгийн монгол хэлээр
8. **APA тайлан:** нэг өгүүлбэр

## APA хэв маягаар тайлагнах

Дүрслэх үзүүлэлтийг (M, SD) заавал хамт бичнэ; df-ийг хаалтад; ач холбогдолтой бол p < α, үгүй бол p > α (программаас гарсан яг p утга байвал түүнийг бич).

- z-тест: z = +2.10, p < .05
- t-тест: t(8) = −3.47, p < .05
- Корреляци: r(28) = +.48, p < .05
- ANOVA: F(2, 12) = 4.52, p < .05; нөлөөний хэмжээ η² = .43
- Хи-квадрат: χ²(1, N = 80) = 6.25, p < .05

Монгол өгүүлбэрийн жишээ: "Сургалтад хамрагдсан бүлгийн оноо (M = 24.0, SD = 3.0) хяналтын бүлгийнхээс (M = 21.0, SD = 3.1) статистик ач холбогдолтой өндөр байв, t(28) = 2.70, p < .05, d = 0.99."

## SPSS

Хэрэглэгч SPSS ашиглаж байвал цэсний замыг өгч, гаралтын аль нүдийг унших, түүнийг номын тэмдэглэгээтэй хэрхэн холбохыг тайлбарла:

- Давтамж, дүрслэх: Analyze → Descriptive Statistics → Frequencies / Descriptives
- Корреляци: Analyze → Correlate → Bivariate; Регресс: Analyze → Regression → Linear
- t-тест: Analyze → Compare Means → One-Sample / Independent-Samples / Paired-Samples T Test
- Нэг хүчин зүйлийн ANOVA: Analyze → Compare Means → One-Way ANOVA (Post Hoc: Tukey)
- Хоёр хүчин зүйлийн ANOVA: Analyze → General Linear Model → Univariate
- Хи-квадрат, эрэмбийн тестүүд: Analyze → Nonparametric Tests; хоёр хэмжээст χ²: Descriptive Statistics → Crosstabs
- "Sig." баганын утга α-аас бага бол ач холбогдолтой. SPSS-ийн Std. Deviation нь номын жижиг sₓ (N−1).

SPSS-ийн хувилбараас хамаарч цэсний нэр өөр байж болохыг сануул.

## Түгээмэл алдаа — шалгах зүйлс

- ΣX² (квадратуудын нийлбэр) ба (ΣX)² (нийлбэрийн квадрат)-ыг андуурах
- Sₓ (N) ба sₓ (N−1)-ийг буруу газар хэрэглэх: дүрслэхэд S, дүгнэх тестэд s
- Хамааралтай түүврийг бие даасан гэж шинжлэх (давтагдсан хэмжилт, хосолсон загварыг анхаар)
- Гурав ба түүнээс олон бүлгийг олон t-тестээр харьцуулах — туршилтын нийт алдаа өснө, ANOVA хэрэглэ
- Нэг талт тестийг өгөгдөл харсны дараа сонгох
- Вариац, SS, χ², F сөрөг гарвал тооцооны алдаа; |r| > 1 мөн адил
- Ач холбогдолгүй үр дүнд нөлөөний хэмжээ, итгэх интервал тайлагнах, эсвэл "нөлөөгүй" гэж батлах
